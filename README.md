# DIN 5008 Brief Editor

Offline editor for business letters following the German DIN 5008 standard. Interface: Deutsch, English, Русский. Runs on macOS, Windows and Linux.

Downloads are on the [Releases](../../releases/latest) page.

## Verify your download
Compare the SHA-256 checksum with `SHA256SUMS.txt` from the release (`shasum -a 256 <file>` on macOS/Linux, `certutil -hashfile <file> SHA256` on Windows).

## Notes
- macOS: signed and notarized by Apple.
- Windows: the installer is not code-signed yet, so SmartScreen may show a warning ("More info" -> "Run anyway").
- Linux: make the AppImage executable (`chmod +x`) and run it.
